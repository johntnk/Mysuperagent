# 群聊回放对照（脱敏）

一个真实研发群约两个半月的历史消息（466 条），逐条交给 Agent 做**观察式回放**的结果：

- [index.html](index.html)：左边群聊、右边 Agent 的反应，可筛选、搜索。下载后用浏览器打开，或通过 GitHub Pages 访问。
- [transcript.md](transcript.md)：同样内容的表格版，可以直接在 GitHub 上看。
- [replay.json](replay.json)：页面使用的脱敏数据。

## 怎么读

- 回放时 Agent 只能看到当时已经出现的消息，看不到图片、视频、附件和链接正文（标注为“附件/图片正文未导出”）。
- 它的发言**从未真正发到群里**，也不会被之后的消息看到；历史上的真人并不知道这些发言。
- 196 条消息只保留了编辑后的版本，按可确认的时间提供（标注为“仅有编辑后版本”）。
- 这次回放使用回放专用的提示词（`src/replay/observer.ts`），与线上 Workflow 的提示词（`src/analysis/planner.ts`）不完全相同。
- 对话中的“Aurora”“Vega”“nexus”“M1”是替换后的产品与系统化名。

## 脱敏方式

| 原内容                                     | 替换为                                               |
| ------------------------------------------ | ---------------------------------------------------- |
| 成员姓名，及只叫名、昵称、“X老师”等变体    | 成员A、成员B……（同一个人始终同一个化名）             |
| 飞书文档、飞书项目链接                     | [飞书文档链接]、[飞书项目链接]                       |
| 公司内部域名、内网 IP 和端口、文件共享路径 | [内部链接]、[内网地址]、[内网服务器]、[内网共享路径] |
| 其他非公开网站链接                         | [外部链接]（公开的 GitHub 和文档链接保留）           |
| 平台 ID、文档令牌、追踪号                  | [ID]、[token]、tr_[trace]                            |
| 公司名、产品和内部系统代号                 | [公司]、Aurora、Vega、nexus、M1                      |

化名映射表只保存在本地，没有进入仓库。脱敏后用脚本检查过：仓库中不包含任何真实姓名（含变体）、真实平台 ID、租户域名或内网地址。
